# Food Recognition and Calorie Estimation

A browser-based food recognition demo. Upload an image to classify it into one of 11 food categories and see an approximate calorie estimate.

## Live website

[Open the Food Recognition website](https://varshagk1.github.io/Food-Recognition-and-Calorie-Estimation-Using-Deep-Learning.github.io/)

## Features

- Food image upload and preview
- Browser-based image classification using a ResNet-18 model
- Confidence score and approximate calorie estimate
- Home, About, Contact, Login, and Sign Up pages

## How to use

1. Open the live website.
2. Select **Upload** and choose a JPG, PNG, or WEBP food image.
3. Select **Predict** to view the result.

The calorie value is an estimate by food category; it does not measure portion size.

## Technology

- HTML, CSS, and JavaScript
- ONNX Runtime Web
- ResNet-18 image classification model
- GitHub Pages

## Limitations

GitHub Pages hosts static websites, so Django features that require a server—such as real account login, account creation, and sending contact messages—are unavailable in this version.
