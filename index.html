About this estimate

This browser-only page uses the project’s ResNet-18 food classifier, converted from the provided PyTorch weights to ONNX. It recognizes 11 food categories. The calorie number is a fixed category reference from the project, not a measurement of the portion size; treat it as a rough estimate.

*The image is processed locally in your browser. The page downloads the model file from this GitHub Pages site and does not upload your photo.
